Privacy Policy

Last updated: November 6, 2026

Moto Shorts Cloud is a private creator-operated tool for the GUSTAVA YouTube channel. This policy explains the way its Google OAuth integration accesses, uses and stores information.

Information accessed

With the Google account holder's consent, the software requests the youtube.upload and youtube.readonly OAuth scopes. These are used only to confirm the authorized channel, inspect uploaded video status, select safe publication windows and upload videos approved by the channel owner.

Data processed and retained

For reliability, the integration may store video IDs, approved video titles, upload receipts, media fingerprints (SHA-256), publication state, scheduling timestamps, and technical error details in the owner's GitHub repository, GitHub Actions or local device. Original media files remain in the owner's storage or approved production artifacts.

Google OAuth client configuration and refresh tokens are stored privately on the owner-controlled computer or as encrypted GitHub Actions Secrets. The app does not store Google passwords or intentionally place OAuth tokens in public source code.

Purpose and sharing

Information is used only to provide the requested YouTube production, uploads, scheduling, duplicate prevention and diagnostics. The operator does not sell, rent or use Google user data for targeted advertising or unrelated analytics. GitHub and Google process information as infrastructure providers under their own terms and privacy practices.

Retention and removal

Data remains only as needed for production provenance, compliance, technical diagnostics or duplicate prevention. The creator can revoke the app at Google Account permissions, delete the YouTube videos in YouTube Studio, and remove private GitHub Secrets and production records under their control. Revoking OAuth access does not itself delete videos already uploaded.

Limited use

Data obtained via Google APIs is used only for the features described above; it is not sold or shared for independent advertising or profiling.

Contact

For privacy issues, contact the owner of the GUSTAVA YouTube Factory project through its publicly available contact options. This is not a service offering to outside users.
